# Microservicio 4: ms-ia

- **Tecnología:** Python / FastAPI
- **Modelos:** Scikit-Learn (Recomendación), TensorFlow / OpenCV / MediaPipe (Diagnóstico biométrico capilar/facial)
- **API:** REST / gRPC

## Estructura Requerida
- `app/api/` (Routers y Endpoints de inferencia)
- `app/services/` (Servicios de visión computacional y modelos ML)
- `app/models/` (Carga y pipelines de Scikit-Learn y TensorFlow)
- `app/core/` (Configuraciones de seguridad y tokens)
