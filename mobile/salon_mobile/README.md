# Aplicación Móvil: salon_mobile

- **Tecnología:** Flutter (Dart) para iOS y Android.
- **Soporte Offline (RF-10, CU-22):**
  - Base de datos local SQLite para almacenamiento temporal de citas, clóset y perfiles.
  - Colas de sincronización para operaciones pendientes de conexión.
  - Modelos ligeros de inferencia biométrica preliminar embebidos con TensorFlow Lite (TFLite).
